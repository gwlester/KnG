# Published teasers

The social-media teasers for posts that have been published, kept for the record. One folder
per post slug (matching `content/blog/<slug>.md`), one file per platform, with the post URL
filled in. `tools/blog_publisher/publish_next_post.py` writes here when it publishes a post
from `content/pending-blogs/`; the first two topics were recovered from git history.
