## Short description (one sentence, shown on alternatives listings)

Builds a church service order and plays it live -- stereo MP3 or MIDI to
your instrument -- so a congregation always has accompaniment, staffed or
not.

## Full description

Virtual Church Musician (VCM) is a set of apps for planning and running
live music in a church service. A Templates app defines reusable service
shapes; a Services app builds a specific week's order from hymns and
chants; a Runner app plays that order live, sending stereo MP3 audio or
MIDI directly to an instrument (or through a MIDI Player) at the right
moment. A Security app and companion Server handle enrollment and
administration across every device on the network. Desktop apps run on
Windows, macOS, and Linux; mobile companions run on Android. The Server
runs fully air-gapped -- no app sends data back to the vendor.

## Platforms

Windows, macOS, Linux, Android

## License / pricing

Freemium. The Admin/Security, Templates, Services, and Runner client apps
are free. The Server and MIDI Player (the two components that actually
play/send audio and MIDI) are commercially licensed -- contact for
pricing.
