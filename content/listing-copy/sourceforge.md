## Project name

Virtual Church Musician (VCM)

## Summary (one line)

Plan a church service and run it live, with automatic MP3/MIDI
accompaniment -- no operator required during the service.

## Full description

Virtual Church Musician is a suite of apps for planning and running the
music portion of a church service. A Templates app defines reusable
service shapes; a Services app builds a specific week's order from hymns
and chants; a Runner app plays that order live, sending stereo MP3 audio
or MIDI directly to an instrument (or through a dedicated MIDI Player) at
the right cue -- automatically, without anyone operating playback by
hand. An Administrator app and mobile Security companion manage device
and user enrollment across a church's network. The Server component runs
fully air-gapped by design: no service, attendance, or usage data is sent
back to the vendor.

Desktop apps (Admin, Templates, Services, Runner -- all free) run on
Windows, macOS, and Linux; mobile companions (Security, Templates,
Services, Runner -- all free) run on Android. The UI ships in English,
Spanish, and German.
