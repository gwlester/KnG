Hardware

VCM Servers and VCM MIDI Players, built out for you

We set up the computer that runs your VCM Server and the VCM MIDI Player that sits next to your organ or keyboard, and get them working with your sound system and instrument. There are two ways to do it:

  • A custom build we sell you. We build the system, configure it, and it arrives ready to use.
  • Installed on hardware you supply. You provide the hardware; we install and configure the software.

We recommend the Raspberry Pi 4 or Raspberry Pi 5. The Server can run on a fully air-gapped network.
