Beta testers

Welcome to the VCM Android beta

Thank you for volunteering to help test the Android apps for Virtual Church Musician. Having real church musicians and volunteers try these out before a wider release is exactly the kind of feedback that makes the software better.

What we're asking

Please install and use the apps for about four weeks, in whatever way fits your normal routine -- building templates, preparing a service, running it live, or just poking around. If anything breaks, feels confusing, or just seems off, we'd love to hear about it. Questions, bug reports, and general impressions are all welcome -- nothing is too small to mention. Reply to the email that pointed you here, or use the contact form.

Trying it with a real Server

Each app has a built-in demo mode that needs nothing else to try. But to really put the apps through their paces, you'll want them connected to an actual VCM Server. If you don't already have one running, request a free 90-day Test Drive and we'll issue you an access code -- it only works with the email address we already have on file for you as a beta tester.
