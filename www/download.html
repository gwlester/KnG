Installing

First-time install notes

The installers are not yet signed by Apple or Microsoft, so your system may ask for an extra confirmation.

Installing on Android

Android apps are provided as APK files. Open the downloaded file. If Android asks, allow your browser or Files app to install unknown apps (the setting is usually under Settings, Apps, Special access, Install unknown apps, and the wording varies by device). Android may also show a Play Protect notice for apps that do not come from Google Play; choose to install anyway if you downloaded the file from this site. Google Play listings are planned.

Installing on macOS

Open the downloaded .dmg and drag the app into Applications. The first time you open it, macOS may say the app is damaged or cannot be opened. That only means the app has not been notarized by Apple yet. Double-click the fix_app_permissions.command file included in the same .dmg once, then open the app normally from Applications.

Installing on Windows and Linux

On Windows, run the downloaded .exe, or double-click the .msi. On Linux, install the .deb, for example with sudo apt install ./file.deb. If your system shows a security prompt for an unsigned installer, that is expected for now.
