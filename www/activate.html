Licensing

Activate a license

Most installs activate automatically from inside the Admin app and never need this page. Use this page only if your Server or MIDI Player has no internet access of its own -- the Admin app will tell you if that's the case and show you the device ID to enter below.

What you'll need

The order reference and activation key from your order confirmation (or trial confirmation) email, and the device ID shown on the Admin app's license screen for the Server or MIDI Player you're activating.

This produces a license file to carry over to that device by USB drive (or however you move files there) and upload through the Admin app -- no internet access on the device itself is needed after this step.
